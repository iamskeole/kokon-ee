# Kokon EE brand assets

Two parts:

- **The Kokon EE wordmark** (this project's): plain "Kokon EE" text in the Inter typeface
  the product already bundles (`@fontsource-variable/inter`). No artwork, no generated
  files — `wordmark/kokon-ee-wordmark.svg` (dark on light) and
  `wordmark/kokon-ee-wordmark-white.svg` (light on dark, the brand paper colour).
  Used in the README header. A Kokon EE icon is a later pass.
- **The inherited Kokon mark and icons** (Gabriele Lozupone's artwork — his copyright per
  NOTICE, not AGPL-licensed): the mark, the app/web/social icons and the generator. They
  stay in this tree until the desktop app and the site are retired; they do not brand this
  project's product surfaces.

## Inherited mark (his artwork)

Generated by `scripts/brand/kokon_brand.py` from one geometric definition of the mark
(variant C, "cocoon + wings": a capsule stem, the cocoon, and two wings, the upper one larger,
emerging from it). Edit the script, not the files, and rebuild:

```
python scripts/brand/kokon_brand.py build c      # needs pillow numpy fonttools brotli skia-pathops
python scripts/brand/kokon_brand.py preview      # variant comparison sheet (explorations/)
```

## Colours

| Name | Hex | Use |
| --- | --- | --- |
| Ink | `#0D0D0D` | mark, wordmark, dark tiles (same as the app's text colour) |
| Paper | `#F7F6F2` | app icon tile, mark on dark backgrounds |

The app UI itself is monochrome (see `src/styles.css`).

## Files

| Folder | What | Where to use it |
| --- | --- | --- |
| `wordmark/` | **Kokon EE** text wordmark (Inter SemiBold, ours) | README header; `-white` on dark backgrounds |
| `icon/kokon-icon*` | light squircle tile with the black mark (inherited) | desktop app (installed into `src-tauri/icons`) |
| `icon/kokon-icon-inverse*` | black tile, light mark (inherited) | website, social avatars, anywhere but the desktop app |
| `icon/macos/` | macOS icon on Apple's template grid (824 px squircle in 1024, 100 px margin, soft shadow), PNGs + `kokon.icns` (inherited) | installed into `src-tauri/icons/macos` (used by `tauri.macos.conf.json`, also the Dock icon in dev) |
| `icon/kokon-app.ico` | Windows icon, 16–256 px each drawn directly (inherited) | copied to `src-tauri/icons/icon.ico` (app, installer, uninstaller) |
| `mark/` | the mark alone on transparent, black and light (inherited) | documents, slides, merch |
| `web/` | favicon.ico/.svg, apple-touch-icon, 192/512 icons (inverse tile, inherited) | website |
| `social/` | 1280×640 preview (inherited) | GitHub social preview, link cards |

## Rules

- Keep clear space around the mark of at least the stem width on every side.
- Do not recolour the parts separately, rotate, stretch or add effects.
- Below 24 px use the icon tile, not the bare mark.

`explorations/` holds the variants considered (A, B, C); C was chosen on 2026-10-08.
